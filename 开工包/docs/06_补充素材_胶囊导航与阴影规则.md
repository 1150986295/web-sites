## 二、CSS 阴影参数规则（可直接复用）

**它是什么**：把"像脏手印"这种模糊描述，转成四条硬性参数界限。这是纯知识，任何站都能用。

### 四条规则

| 参数 | 规则 | 对应 CSS | 参考值 |
|---|---|---|---|
| 偏移 | 默认只向下，X 恒为 0（拟物例外见下） | `0 Ypx` | md 4px / lg 10px / xl 20px |
| 模糊 | 必须 > 偏移 | `Y…blur` | 4→6、10→15、20→25 |
| 扩散 | 只能 0 或负 | `spread` | −1/−2/−3；Material 最多 +2 |
| 颜色 | 不用纯黑 50% | `rgba(0,0,0,.10~.20)` | 别出现 `0,0,0,0.5` |

> **例外：纸感拟物（neumorphism）双向柔光**。模板 A/B 的卡片是"纸面压出来"的效果，光源固定左上，投影在右下、高光在左上，**必须成对出现**：
> `box-shadow: 2px 2px 6px rgba(201,194,176,.55), -2px -2px 6px rgba(255,255,255,.85)`。
> 允许 X≠0 的前提是：① 两条阴影 X/Y 正负对称；② 模糊 > 偏移；③ 深色端不用纯黑，改用带暖色相的暗色（如 `rgba(12,10,6,.5)`），否则会"死黑糊边"。
> 单向投影（卡片浮起、弹层）仍按上表 X=0 执行，两种语言不要在同一组件里混用。

### 两套现成值（直接抄）

```css
/* Tailwind 中档（2 层） */
box-shadow: 0 4px 6px -1px rgba(0,0,0,.10), 0 2px 4px -2px rgba(0,0,0,.10);

/* Material 8dp（3 层） */
box-shadow: 0 5px 5px -3px rgba(0,0,0,.20), 0 8px 10px 1px rgba(0,0,0,.14), 0 3px 14px 2px rgba(0,0,0,.12);
```

### 可直接发给 AI 的提示词模板

> 给卡片加阴影，严格按下面 4 条，不要自由发挥：
> 1 偏移：Y 轴向下，X 恒为 0（例 0 4px）
> 2 模糊：必须大于 Y 偏移（4→6、10→15、20→25）
> 3 扩散：只能用 0 或负值，禁止正值外扩
> 4 颜色：禁用纯黑；用 rgba(0,0,0,0.10~0.20)，或取卡片底色加深作阴影色
> 层数：默认 2 层（近层小而清晰 + 远层大而柔和）；只有高海拔弹层才叠到 3 层
> 全局：一页只设一个光源，所有阴影同方向；卡片越高，偏移与模糊等比放大
> 例外：纸感拟物必须"右下投影 + 左上高光"成对，X 可不为 0；深色端用带色相暗色，不用纯黑
> 输出：直接给 CSS box-shadow，并逐层说明作用

**30 秒验收法**：X 分量是不是 0（拟物例外看正负是否对称成对）；模糊是不是大于偏移；扩散有没有正数；颜色里有没有 `0,0,0,0.5`。四条都对，就不会"脏手印"。
