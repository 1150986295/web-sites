## 一、能不能当通用？分两层看

| 功能 | 逻辑通用性 | 前提 / 坑 |
|---|---|---|
| 关键词高亮 | ✅ 完全通用 | 函数对任意文本生效，必须走 `esc()` 防注入，否则搜索框输入 `<img onerror>` 会 XSS |
| 拼音搜索 | ⚠️ 半通用 | 搜索逻辑通用，但**每条数据要手动标 `py` 字段**——不是自动转拼音。换数据要重新逐条标，量大易漏 |

**一句话**：能当「通用模式」复用（以后做搜索都照这个结构），但不是「免维护组件」（数据换了 `py` 得重标）。

## 二、拼音搜索的正确做法

### 1）数据层：每条加 `py` 字段
```js
{name:'秘塔写作猫', cat:'writing', keys:'秘塔 写作猫 中文 校对', 
 py:'mita xiezuo mao mtxzm mts', ...}
```
- `py` = 全拼 + 首字母缩写，空格分隔，全部小写
- **谁来标**：出码的 AI 逐条标。数据一多（>30条）建议让 AI 生成时一并产出，别事后手工补
- **验收**：随机抽 2-3 条用拼音首字母搜，能命中才算合格

### 2）匹配层：把 `py` 拼进匹配串
```js
function matches(t){
  var kw = STATE.q.trim().toLowerCase();
  if(STATE.cat !== 'all' && t.cat !== STATE.cat) return false;
  if(!kw) return true;
  return (t.name + ' ' + t.keys + ' ' + (t.py || '')).toLowerCase().indexOf(kw) > -1;
}
```
关键：`(t.py || '')` 兜底，老数据没 `py` 字段也不报错。

## 三、关键词高亮的正确做法

```js
function mark(text){
  var kw = STATE.q.trim();
  if(!kw) return esc(text);
  var i = text.toLowerCase().indexOf(kw.toLowerCase());
  if(i < 0) return esc(text);
  return esc(text.slice(0,i)) + '<mark class="hl">' + esc(text.slice(i, i+kw.length))
    + '</mark>' + esc(text.slice(i+kw.length));
}
```
- **三段都走 `esc()`**，这是防 XSS 的命门——搜索框是用户输入，直接拼进 innerHTML 就会注入
- 用 `<mark class="hl">`，CSS 里给 `.hl` 配色（当前是蓝色底）
- **注意**：拼音命中时显示文本里没有拼音字母，所以高亮不会出现——这是正常的，不是 bug。中文/英文命中才高亮。

CSS：
```css
.card mark.hl{background:rgba(110,140,255,.26); color:var(--ink);
  border-radius:3px; padding:0 2px; box-shadow:inset 0 -1px 0 rgba(110,140,255,.6)}
```

## 五、灯箱切图不闪：预加载（2026-11-26 补，墨缘早就有，别再漏）

**症状**：点灯箱左右箭头，**名字变了、图片没变**（或慢半拍）。根因不是逻辑错，是切图时新图要现下载，标题先更新、图片后到。
**这是通用要求**：凡是有「点开大图 + 前后切换」的地方，都必须预加载，墨缘从一开始就做了。

### 正确做法（三件套）

**1）缓存 + 预加载**：打开灯箱时把整组图塞进浏览器缓存
```js
var lbCache = {}, lbLoadToken = 0;
function preloadLB(src){
  if(!src) return null;
  if(!lbCache[src]){ var im=new Image(); im.src=src; lbCache[src]=im; }
  return lbCache[src];
}
function openLB(o){
  lbState.list=o.list||[]; lbState.idx=o.idx||0;
  lbState.list.forEach(function(s){ preloadLB(s.img); });  // 整组预加载
  preloadLB(o.img);
  lbLoadToken++;
  applyFrame(o.img,o.title,o.sub);
  ...
}
```

**2）图文同步 + token 防竞态**：图没好就先淡出，加载完再图文一起换
```js
function stepLB(d){
  lbState.idx=(lbState.idx+d+lbState.list.length)%lbState.list.length;
  var s=lbState.list[lbState.idx];
  var im=preloadLB(s.img);
  var token=++lbLoadToken;   // 连续快点时，只让最后一次生效
  if(im && !im.complete){
    lbImg.style.opacity='.35';
    im.onload=function(){ if(token===lbLoadToken) applyFrame(s.img,s.title,s.sub); };
    im.onerror=function(){ if(token===lbLoadToken) lbImg.style.opacity='1'; };
  }else{
    applyFrame(s.img,s.title,s.sub);
  }
}
```

**3）CSS 过渡**：`.lb-img{transition:opacity .18s ease}`

### 两个必守细节
- **token 防竞态**：连续快点箭头，没有 token 会出现「图跳回旧的那张」。
- **空 src 陷阱**：灯箱 img 初始和关闭时 `src` 不能是 `''`（会请求当前页、触发错误红点），要用内联 1×1 透明 GIF：
  `data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7`

**验收**：打开灯箱后连点 5 次箭头，每次标题和图片都要**同时**变（实测 5/5）。
