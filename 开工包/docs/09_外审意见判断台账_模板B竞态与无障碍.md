## 一、P0 竞态：为什么是真 bug，怎么修的

### 根因（模板B 原版）
```js
function goto(id){
  ...
  const cur = document.getElementById("v-"+current);
  const nxt = document.getElementById("v-"+id);
  cur.classList.add("leaving");
  setTimeout(()=>{
    ...
    current = id;        // ← 200ms 后才更新
  }, 200);
}
```
`current` 在定时器内更新 → 200ms 内连点两次，第二次判断时 `current` 还是旧值，两个定时器都执行 → 两个视图同时 `on`。

**为什么未登录不易暴露**：`post/me/admin` 有 `needAuth` 权限门，未登录时提前 `return`；一登录就暴露。手机上底部标签连点很容易触发。

### 修法（照搬导航站 switchSeq，适配多视图）
```js
let switchSeq = 0;                    // 切场序号，勿删
function goto(id){
  ...
  if(id === current) return;
  const cur = ..., nxt = ...;
  if(needAuth && !WHO.token){ openAuth("login", id); return; }
  const my = ++switchSeq;            // 本次序号；旧序号定时器到点自动作废
  cur.classList.add("leaving");
  setTimeout(()=>{
    if(my !== switchSeq) return;     // 已有更新切场 → 丢弃本次
    document.querySelectorAll(".view").forEach(v=>v.classList.remove("on","leaving","entering"));
    nxt.classList.add("on");         // 统一清理后再点亮，彻底防残留
    current = id;
    ...
  }, 200);
}
```
**两个关键**：① 序号守卫作废旧定时器；② 执行时**统一清理所有 `.view`** 再只点亮目标——多视图结构不能像导航站单页那样只靠 cur 引用，否则会残留。

### 验证（反证法）
- 修前：极速连点 → `['v-list','v-post']` 双视图叠加（复现成功）
- 修后：连点 4 次 + 三连点（list→me→post）→ **每次都只有一个视图 on** ✅

## 二、P1 无障碍三件套（一两行 CSS，低成本）

| 项 | 修法 | 位置 |
|---|---|---|
| 焦点环 | `:focus-visible{outline:2px solid var(--accent); outline-offset:3px}` | 基础 CSS 区 |
| 状态播报 | `<div id="topTitle" aria-live="polite">` | 顶栏标题（切场时播报页名） |
| 禁横向溢出 | `html{overflow-x:hidden}` | 基础 CSS 区 |

**通用性**：这三件套模板A/B 都缺、导航站都有，应作为**所有新模板的默认项**写进骨架。

## 三、P2 / P3 为什么"不立刻做"

- **P2（设计系统）**：阴影三级、二级层级、clamp 首屏字号确实更好，但属于纯视觉升级。按项目"纯视觉微调攒着、不单独发版"的规矩，**并入下次视觉施工**，不为它单开版本。
- **P3（可选模块）**：分类色/mark 高亮/收藏最近，导航站有、模板B 没有。但模板骨架必须保持中性——这些做成"要用再复制"的可选块，别默认塞进骨架，否则模板越滚越重。

> 一句话：**骨架求稳不求全**。A 类（bug/无障碍）立刻补；B 类（视觉）攒着；C 类（可选功能）按需放。

## 四、复用 SOP（收到对模板的意见时）

1. **对版本** —— 先确认评审者看的是哪个版本（本次豆包看的是 V6 实物，所以准确率高）
2. **逐条拆** —— 每条独立归类 A/B/C/D，不打包
3. **实测判** —— 静态审查 + 浏览器实测复现，不信转述（竞态必须亲手连点复现）
4. **查红线** —— 属实的先看门禁查什么，别为迎合破坏骨架
5. **分类处置** —— A 改 / B 换方式或攒着 / C 驳回写理由 / D 认表述不动代码
6. **回归验** —— 改完重跑门禁 + 实测，全绿才算过
7. **留台账** —— 记进本文档，防重复踩

**两处源码同步铁律**：模板B 有两份（`模板B_多页应用/` 与 `网页仓库_sites/tpl-b/`），改动后用 md5 核对一致，否则线上与开工包分叉。本次改后 md5 均为 `cf855e0…`。
