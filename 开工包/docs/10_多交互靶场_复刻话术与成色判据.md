## 二、复刻话术（直接甩给豆包/任意 AI）

```
请做一个单文件 HTML「交互实验室」靶场，深色玻璃拟态风格，断网可开（所有资源内联，
不许任何 http 外链）。必须包含以下交互，每条都要真能用、不许假按钮：

1. 底部 5 个 tab 切场：首页/探索/画廊/收藏/实验室。用统一路由表 ROUTES + goto() 切场引擎。
   关键：极速连点多个 tab 不能出现两个页面叠加——用序号守卫（switchSeq）让旧定时器作废，
   执行时先清所有视图状态再点亮目标。
2. 探索页搜索：中文/拼音全拼/首字母缩写都能命中；命中的关键词高亮（逐段转义防 XSS）；
   输入 120ms 防抖；分类芯片筛选 + 排序下拉；无结果时空态。
3. 画廊页：6 张图用内联 SVG（data URI），点图开灯箱；灯箱支持左右按钮+键盘方向键+Esc 关闭；
   打开时整组预加载大图，切图用 token 防竞态，图文等图就绪再同步变。
   注意：所有 img 的 src 不许为空字符串，用内联透明像素占位，否则浏览器请求当前页会报错。
4. 收藏：探索页点星标收藏，写 localStorage，上限 12 条自动截断；收藏页能看列表。
5. 实验室页：深浅主题一键切换并持久化（CSS 变量换肤）；动效开关；表单逐字段校验
   （必填/邮箱格式/字数）并写 localStorage；"制造一个错误"按钮验证错误红点。
6. 骨架必备：路由表 ROUTES、错误红点（捕获 error 和 unhandledrejection，角落徽标可展开清除）、
   三态 DOM（listLoading/listEmpty/listErr）、设计令牌 :root、focus-visible 焦点环、
   aria-live 状态播报、html overflow-x:hidden。
7. 不许出现任何 AI 平台水印字样，不许用 eval，不许外链图片/CDN。

做完给我完整 HTML 源码（不要预览链接），我要过门禁和浏览器实测。
```

## 五、教训补记：空 src 陷阱（第 2 次踩，务必看）

**现象**：干净加载后右下角就有红点，错误日志显示「脚本错误」但**无行号、无 pageerror、无失败请求**。

**根因**：灯箱 `<img src="">` 空值 → 浏览器把当前页 URL 当图片去请求 → 加载失败冒泡到 window 的 error → 被错误红点捕获。

**修法**：所有 img 的初始 src 用内联透明像素：
```
data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7
```
关闭灯箱重置 src 时也用它，不要赋空串。

**为什么记两遍**：协会页（11/26 凌晨）踩过一次、写进了 `08`；本次靶场（11/26 上午）我又犯了。这说明光写文档不够——**新页面只要出现 `<img src="">`，构建后必须做一次"干净加载看红点"的检查**，这是比门禁更早的一步。已加入第 3 节审核清单。
