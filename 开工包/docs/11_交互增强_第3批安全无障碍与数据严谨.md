# 交互增强 第3批：安全、无障碍与数据严谨（V7 实战沉淀）

> 来源：`ai-tools-nav` V7（2026-11-26）。豆包/新对话在 V6 基础上提出 8 项改进，主对话逐条实测后确认全部属实并上线。
> 这一批的价值不在"功能更多"，而在**看不见的健壮性**：安全、无障碍、数据可信。做展示站时最容易漏，恰恰是接单时最显专业的地方。
> 铁律照旧：**外审意见一律实测再判，不照单全收**（见 docs/09）。本批 8 项我全部亲手复现/反证过。

## 一、8 项改进逐条判定（全部 A 类属实）

| # | 改进点 | 为什么之前没注意到 | 我的实测验证 | 判定 |
|---|---|---|---|---|
| 1 | **safeUrl 协议白名单** | 数据都是 https 硬编码，没人想过数据会被改成 `javascript:` | 用 route 把一条 url 改成 `javascript:alert(1)//`，渲染后危险 href 数 = 0（退化为 `#`） | ✅ A 必改 |
| 2 | **整卡语义链接**：正文包进 `<a>`，星标按钮放 `<a>` 外 | 旧版是空 `<a>` 盖住卡片（`position:absolute;inset:0`），屏幕阅读器读不到标题/简介 | DOM 检查 40/40 卡：h3/p 都在 a 内、星标在 a 外；点星标收藏正常且不误跳转 | ✅ A 必改 |
| 3 | **焦点保护**：重建 DOM 前记住焦点，重建后按 data 属性恢复 | 搜索/筛选会全量 `innerHTML` 替换，键盘用户的焦点被清空、要重新 Tab | 聚焦"Notion AI"星标→搜它自己→焦点仍是该星标（BUTTON） | ✅ A 必改 |
| 4 | **触控目标 ≥44px** | chip 38px、sw 34px，看着没问题，但低于 WCAG 44px 建议 | computed minHeight chip/sw 均 = 44px | ✅ A 必改 |
| 5 | **desc 入搜索匹配串** | 只拼了 name/keys/py/task/why，漏了 desc，用户搜简介里的话搜不到 | 搜"参数与风格全在手"（只在 desc 里）→ 命中 1 | ✅ A 必改 |
| 6 | **红点面板重新读取 localStorage** | 闭包捕获了创建时的旧 `a` 数组，新错误加进来后打开面板看不到 | 注入两条新错误后开面板 → 两条都显示 | ✅ A 真 bug |
| 7 | **深色底阴影改亮色微光** | 阴影颜色是 `rgba(0,0,0,.18)`，深色底上物理不可见，等于没阴影 | 截图确认卡片在近黑背景有层次；公式仍守 X=0、模糊>偏移、扩散为负 | ✅ A 属实 |
| 8 | **3 个失效 URL 修正** | 通义千问/文心/腾讯会议官网改版，旧链接跳错页 | 全部改为现行地址，40 条 URL 全 https | ✅ A 属实 |

另：触控目标移动端从 4 列 grid 改回 flex-wrap（40 工具 + 6 芯片挤不下）、动画延迟 `min(i,8)` 封顶（40 卡最后几张不用等 1.8 秒）、`pinch-zoom` 恢复（无障碍允许缩放）、徽标字号 12px→移动端 13px——这些都是细节，一并吸收。

## 二、可复用代码（做任何卡片列表站都该带上）

### 1. URL 协议白名单（纵深防御）

```js
/* URL 协议白名单：纵深防御——即使数据被改成 javascript: 也不会执行 */
function safeUrl(u){
  var s = String(u || '').trim();
  return /^https?:\/\/\S+$/i.test(s) ? s : '#';
}
// 卡片链接：href 用 safeUrl(t.url)，不要直接 esc(t.url)
```

> 作用：`esc()` 只能防 HTML 注入，挡不住 `href="javascript:..."`。`safeUrl` 补上协议层。

### 2. 整卡语义链接 + 星标外置

```html
<!-- 结构：卡片 div > [星标 button] + [a.card-hit 包住全部正文] -->
<div class="card">
  <button class="star" data-fav="..." aria-pressed="false">★</button>
  <a class="card-hit" href="https://..." target="_blank" rel="noopener noreferrer" data-rec="...">
    <div class="card-top">...图标/分类...</div>
    <h3>标题</h3><p>简介</p>
    <div class="meta">...徽标...</div>
    <span class="visit">访问官网（新窗口）↗</span>
  </a>
</div>
```
```css
.card-hit{display:flex; flex-direction:column; gap:var(--sp-2); flex:1; min-width:0;
  text-decoration:none; color:inherit; cursor:pointer; border-radius:var(--r-l)}
.card-hit:focus-visible{outline:2px solid var(--accent); outline-offset:2px}
```
> 要点：**交互元素不能嵌套**（`<button>` 不能放进 `<a>`）。星标是独立按钮，放 `<a>` 外；正文全进 `<a>`，屏幕阅读器 Tab 时能连续读到标题/简介/徽标。

### 4. 搜索匹配串要拼全字段

```js
return (t.name + ' ' + t.keys + ' ' + (t.py || '') + ' ' + (t.task || '')
```

## 三、验收清单（在本批基础上追加）

给新对话/任意 AI 做卡片列表站时，除 15 项门禁外，逐条打勾：

- [ ] 40 条（或全部）URL 全 https；把一条改成 `javascript:` 测试，`href` 退化为 `#`
- [ ] 每张卡：正文在 `<a>` 内、星标/其他按钮在 `<a>` 外；点按钮不误跳转
- [ ] 搜索/筛选后焦点能恢复；焦点的卡被筛掉不报错
- [ ] chip / 开关 / 按钮 computed `min-height ≥ 44px`
- [ ] 搜一个只出现在 desc 里的词，能命中
- [ ] 连续注入两条错误后打开红点面板，两条都显示
- [ ] 深色主题阴影肉眼可见（亮色微光），浅色主题黑阴影正常
- [ ] 无 `pointer-events` 把卡片点区挡住；`pinch-zoom` 未被禁用
