# 模板A · 单页站 —— 使用说明（复制出新站，20分钟上线）

## 这是什么

一个内置了防坑能力的单页站骨架：设计令牌、三态、错误红点、移动端硬规矩、巡检配置全在。
你只做三件事：**改颜色、换图、改文字**。

## 复制新站五步

1. **复制整个文件夹** `tpl-a/`（仓库根目录下），改名成新项目名
2. **改 3 个颜色**：打开 `index.html`，找到 `:root` 里的
   - `--paper`（底色）
   - `--primary`（主色）
   - `--accent`（强调色，全站唯一，只给底部主操作按钮和红点用）
   改完保存，全站同步变（令牌就是干这个的）
3. **换图**：
   - `assets/hero.jpg` —— 主视觉图（**静态资源，不经 canvas 压缩**：长边 ≤1600px、JPEG 质量 80、单张 <1MB；图没放好页面会自动显示占位，不会白屏）
   - `assets/share.png` —— 分享卡片图（300×300）。**它只对读 `og:image` 的平台有效，不能保证微信聊天缩略图**：微信不抓相对路径、也不认 `og:image`，要控图只能走公众号 JS-SDK 签名或直接把图发出去
4. **改文字**：搜「改：」——所有需要改的文案都带这两个字，逐个替换（标题、副标题、日期地点、介绍、页脚、底部主按钮）
5. **改主操作**：底部按钮 `#actMain` 的 onclick，换成真实跳转（报名链接 /微信号 /地图链接）

## 复制后必须删除的

- 「三态演示」整个 `<div class="demo">` 区块（那是给你看三态长什么样的演示）
- `demoErr` 按钮相关（已在 demo 区块内，一起删）

## 上线前自查（5 分钟）

1. 手机打开：3 秒内见到内容，无白屏（主图没到也有底色+占位）
2. 375 宽：无横向滚动、无文字溢出
3. 底部主按钮点得到、点了对
4. 改一个颜色令牌 → 全站同步变
5. 跑一次巡检：`python3 开工包/tools/网页巡检.py --config <你的配置>.json --out 巡检结果_新站`
   ——配置写法照 `开工包/tools/巡检配置_全仓库.json` 改（把 `files` 换成你的页面）；看输出目录里 `patrol.md` 的 FAIL 表（结论只认"首屏 PASS"）

## 出问题找谁

- 排版错乱 → 检查是不是删掉了令牌引用、写了裸色值/裸字号
- 白屏 → 检查 `<style>` 是否完整闭合；红点脚本勿删
- 想加第二个按钮 → 底部主操作只许一个；其余放内容区
- 更多坑 → 查《症状速查表.md》和《网页施工通用经验与模板_三项目复盘》

## 红线（违反必炸）

- 不加登录、不加后台、不做本地表单收集（要收集就跳第三方）
- 不引第三方 CDN 库（离线打不开就是坏的）
- 正文不许小于 16px；强调色全站只此一个用途
