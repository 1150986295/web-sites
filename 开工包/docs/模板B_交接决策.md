## 阶段2 身份系统（已落地）

- **模拟接口层** `mock()`：与真实后端同形状 `{code,message,traceId,data}`，注册/登录/改密/管理员接口四条。**阶段3换真实后端只替换 mock() 内部实现，调用方零改动**
- **WHO 唯一源**：登录成功双键成对写（内存+localStorage `tplB_auth_v1`）；绝不出现"有token没who"
- **401/403 分流器** `handleAuthError()`：全站唯一身份错误入口。401=清整套回登录层；403=只 toast，绝不清登录态
- **权限门**：needAuth 未登录→弹登录层并记住要去的页（登录后自动续跳）；管理入口 `.gate` 只由 WHO.isAdmin 驱动；普通用户直闯 admin 显示 403 引导态（不给内容但页面正常）
- **首登改密**：注册后 `pwdInit:false`，首次登录自动弹改密层，改完才放行
- **内置演示管理员**（2026-11-27 撤除）：原先全新站点 seed `admin / 123456`；现改为不预置任何账号、首个注册者自动 `isAdmin`，明文默认密码不再进仓库
- **401/403 演示按钮**：管理后台内可"模拟服务端吊销 token"看 401 清登录态全过程

## 阶段3 数据层（已落地）

- **统一接口规范**：全部走 `mock()`，形状 `{code,message,traceId,data}`；错误码 400（参数）/401（登录）/403（权限）/404（未知接口）/409（冲突）+中文 message。**换真实后端只改 mock() 内部，调用方零改动**
- **分页**：`listItems` 返回 `{list,total,page,pageSize}`（每页 5 条，PAGE_SIZE 单点定义）；UI 用"加载更多"不跳页码；列表三态（loading/空/错误）全由接口状态驱动，页面零手写数据
- **幂等提交**：双闸——前端 `POSTING` 标记+按钮禁用拦截同帧双击；接口层 `idemKey` 幂等键，同一意图重复请求只落一条（双发同键实测：第二条返回"已收录（幂等去重）"）
- **备份导出**：管理员专用（403 拦普通用户）；下载 JSON；**账号表脱敏**（绝不吐密码字段）
- **备份导入**：本地先验 JSON 可解析 → 接口验结构（缺 items/条目不完整**整包拒绝**）→ 按 id 去重合并；实测同份备份重导=全跳过、坏文件=拒绝且数据零污染、新条目=正常合入
- **列表刷新机制**：发布/导入后置 `LIST.dirty`，下次进列表页重拉第一页

> 巡检经验（写进通用经验）：动作回放比页面切场快会产生假 FAIL——提交后跳页/切场/接口共需约 1.5s，断言前要 wait；在切场中途（200ms 退场未完成）点目标 tab 会被 goto 判为"当前页"直接 return，导致后续 fill 打在隐藏视图上。排查思路：FAIL 连锁时先看链条第一环是时序还是真 bug。

## 阶段4 上传后台（已落地）

- **图片压缩**：前端 canvas 压副本（长边 1080、JPEG 80%），**原图不动**；压缩结果以证据式文案展示（2000×1500 73KB → 1080×810 14KB）；压完仍超 300KB 提前预警，接口侧 400 兜底
- **进度条**：阶段式（选图12%→读取32%→解码60%→压缩100%），只动 width（唯一豁免"禁 width 动画"：状态指示非布局动画，已写注释）
- **失败重试**：读文件/解码/压缩任一失败→进度条变红+现场保留（表单内容、已填字段不丢），换图重试；提交失败现场全保留
- **批量删除二次确认**：复选+全选+计数联动按钮；确认弹层**必须输入"删除"两个字**（空词/错词都被拦，数据零变动）——绝不裸 confirm()
- **操作留痕**：后端写操作（发布/批量删除/导入/导出）统一记 `谁+何时+干了什么`（上限 100 条），管理后台展示最近 20 条；普通用户查留痕 403
- **接口层新增**：`deleteItems`（403 管理员专用）、`getLogs`（403 管理员专用）、`addItem` 扩展 `image` 字段（长度 400 上限校验）

## 阶段5 动效打磨（已落地，模板B收官）

- **级联调参**：入场级联从 5 级扩到 8 级（列表卡片多页场景），间隔 .05s 等差；CSSOM 断言保证退场只动 opacity、级联只动 opacity/transform（禁 height/width/display 写进自检）
- **无障碍**：`prefers-reduced-motion: reduce` 时全部过场动画归零（级联/退场/骨架屏/toast），结构不动只关动效
- **进度分母唯一（由数据算）**：加载更多按钮显示"已看 5 / 共 8"、到底显示"共 8 条，已全部加载"——分母全部来自接口 total，页面零手写数字
- **深色模式**：`prefers-color-scheme: dark` 整套令牌换肤（只改 :root 全站跟随）；**对比度用工具实测**而非目测：浅色 11.44:1、深色 12.44:1（均超 WCAG AA 正文 4.5 要求）
- **巡检升级**：支持 `color_scheme`/`reduced_motion` 模拟与 `contrast_check` 对比度计算（算亮度比，不凭感觉）
