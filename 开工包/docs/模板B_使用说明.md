# 模板B · 多页应用骨架 —— 使用说明（带后台系统的站，从这里起步）

## 这是什么

"要登录、要后台、多人用数据"类站点的骨架。已完成：**阶段1 骨架**（路由表、切场引擎、布局壳）、**阶段2 身份**（注册/登录/改密、WHO 唯一源、401/403 分清）、**阶段3 数据**（分页、幂等提交、备份导出导入）。
上传后台（阶段4）、动效打磨（阶段5）按需接，每阶段过阶段门。

## 演示账号

全新站点自动内置 `admin / 123456`（演示管理员，**上线前删除或改密**）。

## 复制成新项目（8 步）

1. **复制整个文件夹** `模板B_多页应用/`，改名
2. **改 3 色**：`:root` 里 `--paper`（底色）/`--primary`（主色）/`--accent`（强调色）
3. **加页面：必须先改路由表** `ROUTES`，再写 `<section class="view" id="v-xxx">`
   —— 路由表是唯一来源，加了页面没登记，**启动时红点直接报错**（这是特性不是 bug）
4. **tab 改名**：底部 `<nav class="tabbar">` 里的按钮，`data-goto` 值必须等于路由表键名
5. **删占位内容**：各视图里的"占位/演示"卡片，换成真实业务
6. **接身份**：已内置，改文案即可；规矩见 HANDOVER"阶段2"节（登录双键成对写 WHO、401 清整套、403 绝不清、`.gate` 只认 WHO.isAdmin）
7. **接真实后端**：只替换 `mock()` 函数内部实现（保持 `{code,message,traceId,data}` 形状），所有调用方零改动；分页返回 `{list,total,page,pageSize}`；写操作带 `idemKey` 幂等
8. **首个真实账号标管理员**：删掉演示账号 `admin/123456` 后，**第一个注册的账号自动成为管理员**（兜底已内置，2026-11-25 补）；若账号表非空需要追加管理员，在管理后台或 storage 的账号表里把该账号 `isAdmin` 改为 `true`——**不标的话管理后台永远进不去且页面无任何提示**

## 骨架已固化的坑（复制即免疫）

| 坑 | 骨架里的免疫机制 |
|---|---|
| 两个入口跳同一页 / 入口对不上 | 路由表唯一来源 + 启动自检，未登记入口启动即红点报错 |
| 切页像划照片 | 切场引擎统一走 `goto()`，只动 opacity/transform，200ms 退场 |
| 动画重复播 | `ENTER_SEEN` 幂等标记，每个视图只播一次入场 |
| 保存按钮点不到 | 内容区 flex 自动扣掉 topbar+tabbar，弹层同规则 |
| 装饰盖住按钮 | z-index 分层写死：交互 900 / 装饰 <900 / 红点 9990 |
| 白屏 | body 底色在 `<style>` 首部；红点常驻 |
| 大量口算高度 | tab 高度只有 `--tab-h` 一处定义，改一处全站变 |
| 401/403 分不清导致误清登录 | `handleAuthError()` 全站唯一分流器：401 清整套回登录层、403 只 toast |
| 有 token 没 who（登录态写一半） | `saveWHO()` 双键成对写，启动恢复时校验 token 仍有效 |
| 连点提交落重复数据 | 双闸：前端 POSTING 标记+按钮禁用；接口层 idemKey 幂等键，同键重复请求只落一条 |
| 导入坏备份污染全库 | 导入先本地校验 JSON 可解析，再接口校验结构，**坏文件整包拒绝**；按 id 去重合并 |
| 备份里带密码泄露 | 导出接口只吐脱敏字段（无密码），规矩写死在接口里 |
| 列表手写死数据不同步 | 列表只认接口；发布/导入后置 `LIST.dirty`，下次进页重拉 |
| 大图直接入库把库撑爆 | 前端 canvas 压副本（长边1080/JPEG80%），原图不动；压缩结果以"原图→压后"证据文案展示；接口侧再兜底拒超 300KB |
| 上传失败丢掉已填内容 | 读文件/解码/压缩失败进度条变红+现场保留；提交失败表单和附图全保留，重试不重填 |
| 误触批量删除误删数据 | 必须勾选+计数联动按钮；确认弹层必须输入"删除"两个字，空词/错词都拦，数据零变动 |
| 出了问题查不到谁干的 | 写操作后端统一留痕（谁+何时+干了什么），管理后台可查最近 20 条 |

## 上线前自查

1. 逐个点 tab，对照"tab → 页面"（阶段门清单）
2. 连续进出每个页面 3 次：无重复播、无闪断
3. 375 宽无横向溢出
4. 跑巡检：`python3 tools/网页巡检.py --config 巡检配置.json --out 巡检结果_新站`
5. 结论只写"首屏 PASS"
6. **导出一次 JSON 备份**，确认文件能打开、数量对得上
7. 删演示管理员账号（或改密）

## 红线

- 路由表外不许有第二套跳转写法（不许 `location.hash=...` 乱跳）
- 身份只认 `WHO` 一个源，全局搜 `isAdmin` 只许出现一次（WHO 里那个）
- 红点 `<script>` 保持最后一个；捕获脚本先于业务脚本
- 强调色只给主操作+红点
- 数据永远只从接口来（`mock()` 或真实后端），页面不许手写死数据
- 每次动数据结构（加字段/改字段）前：先导出备份
