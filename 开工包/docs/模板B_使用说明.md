# 模板B · 多页应用骨架 —— 使用说明（带后台系统的站，从这里起步）

> ## ⚠️ 仅限离线 DEMO，禁止直接当生产系统上线
>
> 本模板的身份系统是**纯前端模拟（mock）**：账号表、**明文密码**、登录 token 全部存在浏览器的
> `localStorage` 里。任何会用 F12 的人都能：
> - 打开 `localStorage.tplB_users_v1` 直接读出所有人的密码；
> - 把某个账号的 `isAdmin` 改成 `true`，立刻变成管理员；
> - 自己伪造一条 token 写进 `tplB_tokens_v1` 冒充已登录。
>
> 它只用来演示"登录 / 权限 / 后台 / 数据"这套**界面与流程**长什么样。
> **真实站点必须换成服务端认证**：密码加盐哈希、token 由服务端签发与校验、权限只在服务端判定，
> 见文末「生产前必须做的事」。别把 demo 的 `mock()` 当成真的安全边界。

## 这是什么

"要登录、要后台、多人用数据"类站点的骨架。已完成：**阶段1 骨架**（路由表、切场引擎、布局壳）、**阶段2 身份**（注册/登录/改密、WHO 唯一源、401/403 分清）、**阶段3 数据**（分页、幂等提交、备份导出导入）、**阶段4 上传后台**（单图压缩、软删除回收站、操作留痕、后台分页）。阶段5 动效按需打磨。

## 能力边界（文档与实现对齐，别照规格书想当然）

| 能力 | 骨架现状 | 超出部分怎么接 |
|---|---|---|
| 图片上传 | **单图**（一张，长边 1080 / JPEG 80 / 压后 ≤300KB） | 要多图：把 `image` 改成 `images[]`，上传队列逐张压、逐张入数组；列表渲染加缩略图带 |
| 删除 | **软删除**：打 `deleted:true`，列表过滤；导出备份带 `deletedItems`，可找回 | 要回收站界面：后台加"含已删"筛选与恢复按钮 |
| 后台列表 | 每页 20 条 + 上/下一页 + 总数/回收站计数 | 要按标题/作者筛选：给 `listItems` 加参数，前端加筛选条 |
| 备份 | 内容全量（含回收站）+ 账号名单脱敏；**导入不恢复账号** | 要恢复登录：账号必须走注册/后台建号，备份里没有密码 |
| 身份 | 纯前端 mock，`localStorage` 明文 | 生产必须换服务端认证，见文末清单 |

## 账号（无内置演示账号）

全新站点**不预置任何账号**，也不存在明文默认密码（2026-11-27 撤掉了旧的 `admin / 123456` 种子）。
**第一个注册的账号自动成为管理员**（`isAdmin:true`），弹层会显示"创建管理员"，复制成新项目后直接注册即可进后台。

密码仍然是**明文存在浏览器里**的——这是 demo 的取舍，不是可上线的做法。真站点的密码必须在服务端加盐哈希，前端永远拿不到。

## 复制成新项目（8 步）

1. **复制整个文件夹** `tpl-b/`（仓库根目录下），改名；**顺手把 `window.__SITE__` 改成新项目名**——存储键由它派生，不改就会和同域名的其他模板站共用账号/数据
2. **改 3 色**：`:root` 里 `--paper`（底色）/`--primary`（主色）/`--accent`（强调色）
3. **加页面：必须先改路由表** `ROUTES`，再写 `<section class="view" id="v-xxx">`
   —— 路由表是唯一来源，加了页面没登记，**启动时红点直接报错**（这是特性不是 bug）
4. **tab 改名**：底部 `<nav class="tabbar">` 里的按钮，`data-goto` 值必须等于路由表键名
5. **删占位内容**：各视图里的"占位/演示"卡片，换成真实业务
6. **接身份**：已内置，改文案即可；规矩见 HANDOVER"阶段2"节（登录双键成对写 WHO、401 清整套、403 绝不清、`.gate` 只认 WHO.isAdmin）
7. **接真实后端**：只替换 `mock()` 函数内部实现（保持 `{code,message,traceId,data}` 形状），所有调用方零改动；分页返回 `{list,total,page,pageSize}`；写操作带 `idemKey` 幂等
8. **首个注册账号自动当管理员**：账号表为空时，**第一个注册的账号自动 `isAdmin:true`**（2026-11-25 补的兜底；2026-11-27 起不再预置演示账号，注册弹层标题直接显示"创建管理员"）；若账号表非空需要追加管理员，在管理后台或 storage 的账号表里把该账号 `isAdmin` 改为 `true`——**不标的话管理后台永远进不去且页面无任何提示**

## 骨架已固化的坑（复制即免疫）

| 坑 | 骨架里的免疫机制 |
|---|---|
| 两个入口跳同一页 / 入口对不上 | 路由表唯一来源 + 启动自检，未登记入口启动即红点报错 |
| 切页像划照片 | 切场引擎统一走 `goto()`，只动 opacity/transform，200ms 退场 |
| 动画重复播 | `ENTER_SEEN` 幂等标记，每个视图只播一次入场 |
| 保存按钮点不到 | 内容区 flex 自动扣掉 topbar+tabbar，弹层同规则 |
| 装饰盖住按钮 | z-index 分层写死：交互 900 / 装饰 <900 / 红点 9990 |
| 白屏 | body 底色在 `<style>` 首部；红点常驻 |
| 大量口算高度 | tab 高度只有 `--tab-h` 一处定义，改一处全站变 |
| 401/403 分不清导致误清登录 | `handleAuthError()` 全站唯一分流器：401 清整套回登录层、403 只 toast |
| 有 token 没 who（登录态写一半） | `saveWHO()` 双键成对写，启动恢复时校验 token 仍有效 |
| 连点提交落重复数据 | 双闸：前端 POSTING 标记+按钮禁用；接口层 idemKey 幂等键，同键重复请求只落一条 |
| 导入坏备份污染全库 | 导入先本地校验 JSON 可解析，再接口校验结构，**坏文件整包拒绝**；按 id 去重合并 |
| 备份里带密码泄露 | 导出接口只吐脱敏字段（无密码），规矩写死在接口里 |
| 列表手写死数据不同步 | 列表只认接口；发布/导入后置 `LIST.dirty`，下次进页重拉 |
| 大图直接入库把库撑爆 | 前端 canvas 压副本（长边1080/JPEG80%），原图不动；压缩结果以"原图→压后"证据文案展示；接口侧再兜底拒超 300KB |
| 上传失败丢掉已填内容 | 读文件/解码/压缩失败进度条变红+现场保留；提交失败表单和附图全保留，重试不重填 |
| 误触批量删除误删数据 | 必须勾选+计数联动按钮；确认弹层必须输入"删除"两个字，空词/错词都拦，数据零变动 |
| 出了问题查不到谁干的 | 写操作后端统一留痕（谁+何时+干了什么），管理后台可查最近 20 条 |

## 上线前自查

1. 逐个点 tab，对照"tab → 页面"（阶段门清单）
2. 连续进出每个页面 3 次：无重复播、无闪断
3. 375 宽无横向溢出
4. 跑巡检：`python3 tools/网页巡检.py --config 巡检配置.json --out 巡检结果_新站`
5. 结论只写"首屏 PASS"
6. **导出一次 JSON 备份**，确认文件能打开、数量对得上
7. 删演示管理员账号（或改密）

## 红线

- 路由表外不许有第二套跳转写法（不许 `location.hash=...` 乱跳）
- 权限只从**单一身份对象**派生：前端一律读 `WHO.isAdmin`；账号表里的 `isAdmin` 是数据字段、接口必须回查账号表，这两处不算并行身份源。禁止再引入 `isAdmin2` / `role` 之类的影子变量（想加角色就先改 `WHO` 的形状，别另起一套）
- 红点 `<script>` 保持最后一个；捕获脚本先于业务脚本
- 强调色只给主操作+红点
- 数据永远只从接口来（`mock()` 或真实后端），页面不许手写死数据
- 每次动数据结构（加字段/改字段）前：先导出备份

## 生产前必须做的事（mock → 真后端）

上线前逐条打勾，缺一条都不要当"已经能用了"：

- [ ] **密码**：服务端加盐哈希（bcrypt/argon2），`users` 表里**不存明文**，接口不回传密码字段
- [ ] **token**：服务端签发（JWT 或 session），带过期时间；前端只存，不自己造
- [ ] **权限**：`isAdmin` 只在服务端判断，前端隐藏入口只是"看不见"，不是"进不去"
- [ ] **接口鉴权**：每个写接口都校验 token 与角色，别信前端传来的 `authorId`
- [ ] **确认没有内置账号**：全新部署后账号表应为空（首个注册者即管理员）；**从旧版本升级**的要删掉遗留的 `admin/123456`，并确认账号表里没有其他 `pwdInit:true` 的弱密码账号
- [ ] **传输**：全站 HTTPS，否则 token 在链路上就是明文
- [ ] **备份**：接真实数据库的定时备份，别依赖前端"导出 JSON"当唯一备份

一句话：本模板交付的是**界面结构与交互流程**，安全边界必须由服务端补齐。
