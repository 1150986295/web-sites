# 接入说明 · 把交互参考库并入网页通用模板

本说明用于指导把本次交付的交互参考文件并入你的「网页通用模板」，供以后新建 AI 网页时参考。

## 交付文件清单

| 文件 | 作用 | 放置建议 |
| --- | --- | --- |

| `INTERACTIONS.md` | AI 知识库主文件：场景速查表 + 全量索引 + 87 项详情 | 模板根目录，或 `docs/` 下 |

| `interactions.json` | 机器可读数据，供脚本/程序化检索 | 模板根目录，或 `data/` 下 |

| `交互效果速查.html` | 可视化参考页：搜索 + 分类筛选 + 展开详情 | 模板根目录，或 `reference/` 下 |


## 接入步骤

1. 将上述 3 个文件复制到模板项目的合适目录（建议统一放 `reference/` 便于管理）。

2. 在模板的「使用说明 / README」里加一行指引：

   > 新建网页涉及交互效果时，先查阅 `reference/INTERACTIONS.md` 的场景速查表。

3. 让 AI 在生成网页前读取 `INTERACTIONS.md`（或 `interactions.json`），按场景挑选交互并遵守验收条件。

4. 如需人工浏览，直接打开 `交互效果速查.html`。


## 给 AI 的调用约定（可直接写进模板的 system prompt）

```text

生成网页时如需交互效果：

1. 读取 INTERACTIONS.md 的「场景速查表」，选出最匹配的 1-3 个效果。

2. 按详情中的「实现要点」落地，遵循「验收条件」。

3. 所有动画提供 prefers-reduced-motion 静态替代。

4. 优先原生 CSS/JS，避免为单个效果引入重依赖。

5. 不照搬参考库文案，代码按当前页面语义重写。

```


## 归属与维护

- 数据来自公开站点 vibehub.xin 的整理归纳，已转为本地结构化资产，不依赖外部服务。

- 新增/删减交互时，同步更新 `INTERACTIONS.md`、`interactions.json`、`交互效果速查.html` 三处。

- GitHub 提交与发布由你另一处的对话负责；本包只负责产出文件，不含版本控制操作。
